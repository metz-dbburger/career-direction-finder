# career-direction-finder

中文 | [English](README.en.md)

一个 Claude skill：根据你的过往经历和兴趣，推荐几类适合的工作，并在网上找到真实岗位的申请链接。

## 流程

1. **了解背景**：一次问完，最多 4 个问题（经历、兴趣、想在哪里找和找哪一类、硬性限制）。已经说过的不再问，也可以直接发简历。
2. **推荐工作类型**：给 3–5 类，每类一句为什么适合、一句主要差距。不打分，不排名。
3. **找岗位链接**：每类找 2–3 个真实岗位，打开核实后列出链接。打不开或需要登录的页面会标明没有核实。

## 安装

1. 下载本仓库里的 `career-direction-finder` 文件夹，压缩成 ZIP（文件夹要在压缩包的最外层）。
2. 在 Claude 的设置里找到 Skills，上传这个 ZIP。
3. 对 Claude 说"帮我看看我适合什么工作"之类的话即可触发。

找岗位链接需要 Claude 开启网页搜索。没有搜索时，只会给出工作类型和搜索关键词。

## 注意

- 岗位信息以招聘页面为准，投递前请自己再确认一次是否仍在招。
- 签证和工作许可相关的内容只是转述页面上写的，不是法律意见。
